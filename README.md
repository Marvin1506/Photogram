# Photogram – Social Media Frontend Project

This project is a desktop-focused Instagram-inspired social media web application built with HTML, CSS, and JavaScript. The main goal of the project was to strengthen fundamental frontend development skills and improve understanding of JavaScript logic and dynamic content handling.

The project focuses on interactive user interface behavior, comment management, and dynamic rendering using JavaScript.

## Features

* Instagram-inspired user interface
* Dynamic post rendering
* Add and delete comments functionality
* JavaScript-based comment handling
* Interactive user experience
* Structured feed and post layouts
* Desktop-optimized design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## What I Learned

This project helped me improve my understanding of:

* JavaScript fundamentals
* Working with arrays and index handling
* Using for loops for dynamic rendering
* DOM manipulation
* Creating and deleting dynamic content
* Event handling
* Structuring frontend applications
* UI design with HTML and CSS
